# v0.2.0 收尾 Decision Record

status: "deferred"

## 1. Background

**Triggering event:** v0.2.0 的核心假设是——在事实证据层（fact evidence）之上叠加一层面向 AI 消费的 **置信度 / 证据价值标注**（confidence / value labels），能让 decay 输出的风险证据比“一个只读 PR diff 的 AI”更有 review 价值，或至少与之互补。为了诚实检验这个假设，本轮冻结了一份 head-to-head v1 评测资产（`eval/head-to-head/manifests/v1.toml`，sha 锁定 prompt 与 schema），在 40 个真实开源 PR 上对比三条管线：decay fact-only、decay semantic-filtered、以及只看 diff 的 AI baseline。

**Constraints:**
- 评测方法冻结，阈值是 freeze 的一部分，不允许为了让某条管线通过而下调（README 明确禁止）。
- AI baseline 的 fairness 边界由 runner 强制：只看 `diff.patch` 与 `changed_files.txt`，看不到 PR title / body / discussion / linked issue / CI logs。
- “明显胜出”规则：4 个指标里至少通过 3 个才算 decay 明显优于 AI baseline。
- 不得用单个命中 case 宣称产品成功；结论以冻结 cohort 上的聚合指标为准。

**Decision scope:** 本决策处理“v0.2.0 置信证据层假设是否成立、是否发布、v0.3 走向”；不决定具体的新 metric、CI 集成或多语言支持。

## 2. Decision

**We decided:** 不发布 v0.2.0 的语义 / 置信证据层作为产品成果，将其冻结为一个**诚实的负结果（negative result）**，并把项目状态置为 `deferred`。

### 为什么置信证据层没有明显优于 AI 直接读 diff

冻结评测的真实数据（`eval/reports/head-to-head-v1.md`，2026-06-08 重新生成）给出了决定性结论。ai-baseline 实判 34 个 case（≥30 的有效样本门槛达成），decay 两条管线对 AI baseline 的四项阈值**都是 0 / 4 通过**：

| Metric | fact-only | semantic-filtered | ai-baseline |
|---|---:|---:|---:|
| precision@top3 | 42.00% | 69.23% | 61.62% |
| actionable_pr_rate | 52.50% | 45.00% | 100.00% |
| missed_high_risk_count | 27 | 30 | 8 |
| weak_only_top_risk_count | 62 | 35 | 0 |

一个 Opus 级模型仅凭 diff 就能高精度地命中 ground-truth 机制：它的 top3 精度（61.6%）已经超过 fact-only（42%），semantic-filtered 虽到 69.2% 但仅领先 +7.6pp，低于 +10pp 的硬门槛；它的 actionable 率是 100%，而 decay 只有 45–52%；它只漏掉 8 个高价值风险，decay 漏 27–30 个；它产生 0 个 weak-only 噪音 top risk，decay 则有 35–62 个。换句话说，decay 赖以立项的核心假设——“一个静态证据 CLI 能稳定地发现 AI 读 diff 时会漏掉的 review 风险”——被直接证伪。根因是：真正高价值的风险（API / protocol / 行为契约变化）是**语义的，不是结构的**，静态指标看不到它们；而置信度标注只能对已有信号重排序、压噪音，**无法补出缺失的事实**（M3.1 早已证明语义改写不能补缺失事实）。因此再精细的 label 也关不上这道差距。

### 诚实的方法学保留意见

ai-baseline 的输出与 judge 同属 Opus 家族，judge 给 AI baseline 100% actionable，存在对同源输出偏宽松的可能；同时 34/40 的 ai 判定意味着 6 个 case 缺席。但即便对这些保留意见打折，两条管线在四项指标上都是 0/4、且差距极大（actionable 落后 47–55pp、weak-only 多出 35–62 个），这些 caveat 无法翻转结论。

## 3. Alternatives

- **A. 按 Path A 发布 v0.2.0（released）**：数据不支持，四项阈值 0/4 通过，直接排除。
- **B. 宣布 pivot 到“互补 AI”的新 thesis**：方向可能对，但“decay 让 AI+decay 优于 AI-alone”这个互补假设**尚未被任何数据验证**，现在就把它写成新 thesis 等于再造一个未验证的承诺。
- **C. deferred（采纳）**：承认置信证据层假设失败，暂不发布，把下一步收敛成一个**可证伪的门控实验**，验证通过才继续、不通过则考虑终止。

## 4. Impact 与 v0.3 走向

**这是本项目的第 3 次方向调整**（函数级退化检测 → fact evidence 层 → 置信证据层）。按 know 规则，连续 reframe ≥2 次通常意味着 core thesis 从一开始就没站稳，而不是“在精进”。这次 head-to-head 是第一次对“静态证据能改变 AI 协作 review 决策”做正面、冻结、可复跑的检验，结论是否定的。因此 v0.3 不再叙事化为迭代，而是设一道硬 gate：

- **v0.3 唯一实验**：在同一冻结 cohort 上测 **AI-alone vs AI-given-decay-evidence**——即把 decay 的证据喂给 AI，看它能否让 AI 的 review 比 AI 裸读 diff 更好。
- **预注册硬门槛**：AI+decay 相对 AI-alone 必须在等成本下取得可测增益（如 precision +10pp 或 missed -5），否则判定 decay 作为“喂给 AI 的证据层”也无独立价值。
- **决策规则**：gate 通过 → 把 thesis 重写为“确定性、可复跑、低成本的 AI 证据底座 / CI 场景（按 PR 跑 Opus 不现实时）”并继续；gate 不通过 → 终止产品，不再 reframe。
- **约束**：在该 gate 触发前，不发布 v0.2.0、不展开 v3/v4 的细节 scope、不新增 metric。

**Follow-up actions:**
- roadmap 把 v0.2.0 状态从 active 改为 deferred，并标注 head-to-head v1 为负结果。
- 保留 `eval/head-to-head/judgements/` 的 34 份 ai_baseline 判定与 `eval/reports/head-to-head-v1.md` 作为该结论的可复跑证据。

## 5. Status

**deferred** — v0.2.0 置信证据层不发布，冻结为负结果；v0.3 以单一门控实验决定继续或终止。
