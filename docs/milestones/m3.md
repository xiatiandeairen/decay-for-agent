# M3 — v0.2.0 Semantic Evidence

## 1. Goal

### Definition of Done

`decay diff <git-ref>` 在 fact evidence 之上输出 semantic findings。

每条 semantic finding 必须包含：

- `claim`
- `supporting_facts`
- `source_refs`
- `confidence`
- `limitation`
- `review_action`

约束：

- 保留底层 fact evidence。
- Top risk 必须回链到 fact evidence 或外部 source。
- `mixed_concerns`、`blast_radius`、history、纯 `touched_existing_risky` 不得单独进入 Top risk。
- 不输出 merge recommendation。
- 不声明 bug。

### Value Target

相对 v0.1.1 fact-only baseline，提升 Top risk 的行动价值：

```text
precision_at_top3: 65% -> >= 75%
actionable_pr_rate: 60% -> >= 70%
negative_control_silence_rate: 100% -> >= 90%
missed_high_risk_count: 2/10 -> <= 1/20
weak_only_top_risk: 3/10 -> <= 2/20
```

### Hypotheses

- **H1**: semantic findings 能降低 weak-only Top risk。
- **H2**: semantic findings 能减少 API/protocol/behavior 类高价值漏报。
- **H3**: semantic findings 能保持 source traceability，不退化为主观判断。

## 2. Plan

### Planned Deliverables

- semantic finding schema。
- semantic ranking and suppression。
- bad-case regression pack:
  - API surface
  - protocol behavior
  - behavior gate / config boundary
  - move/refactor suppression
  - negative controls
- local DB semantic tables:
  - semantic findings
  - fact-to-claim links
  - judgement feedback
- optional external context ingestion:
  - PR title/body
  - review comments
  - linked issue
  - CI failure
  - decision docs
- 20-case benchmark report comparing:
  - v0.1.1 fact-only output
  - v0.2.0 semantic-filtered output

### Go/No-Go Criteria

| Dimension | Criterion |
|-----------|-----------|
| Output | `diff` prints semantic findings and fact evidence |
| Traceability | 100% Top risk has source refs |
| Weak signal handling | weak-only signals do not enter Top risk |
| Benchmark | 20-case targets reached |
| Quality | `cargo fmt -- --check`, `cargo test`, `cargo clippy -- -D warnings` pass |
| Scope | `doctor` hot debt remains deferred |

### Decision Path

- **Pass**: 20-case benchmark reaches targets; prepare v0.2.0 closeout.
- **Fail**: benchmark misses targets; fix ranking/suppression or bad-case coverage before adding more data sources.

### Risks

- Semantic layer becomes unverifiable subjective judgement.
- External context masks weak fact evidence.
- Bad-case rules overfit the first 10 cases.
- Negative-control silence regresses.
